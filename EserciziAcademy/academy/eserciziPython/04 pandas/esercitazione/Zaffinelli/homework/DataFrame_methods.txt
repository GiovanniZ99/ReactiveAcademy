- Aggregazioni e Statistiche
*agg() / aggregate() → Applica funzioni di aggregazione alle colonne
*all() → Restituisce True se tutti gli elementi sono veri
*any() → Restituisce True se almeno un elemento è vero
*count() → Conta i valori non NaN
*corr() → Matrice di correlazione tra colonne numeriche
*corrwith() → Correlazione con un'altra serie o DataFrame
*cov() → Matrice di covarianza
*cummax() / cummin() / cumprod() / cumsum() → Cumulative max/min/prodotto/somma
*describe() → Statistiche riassuntive
*diff() → Differenza tra valori consecutivi
*kurt() / kurtosis() → Curtosi della distribuzione
*max() / min() → Massimo e minimo
*mean() → Media
*median() → Mediana
*mode() → Moda
*nunique() → Conta i valori unici
*quantile() → Percentili
*rank() → Rank dei valori
*sem() → Errore standard della media
*skew() → Asimmetria della distribuzione
*std() → Deviazione standard
*sum() → Somma dei valori
*var() → Varianza
*
- Selezione e Filtraggio
*at[] / iat[] → Accesso a un singolo valore
*loc[] / iloc[] → Selezione basata su etichette o indici
*filter() → Filtra colonne o righe con criteri specifici
*first() / last() → Prime/ultime righe basate sull'indice temporale
*head(n) / tail(n) → Prime/ultime n righe
*idxmax() / idxmin() → Indice del valore massimo/minimo
*isin() → Controlla se i valori sono in una lista
*nlargest(n) / nsmallest(n) → I n valori più grandi/piccoli
*
- Gestione dei Valori Mancanti
*isna() / isnull() → Identifica valori NaN
*notna() / notnull() → Identifica valori NON NaN
*dropna() → Elimina righe/colonne con NaN
*fillna(value) → Sostituisce NaN con un valore
*ffill() / pad() → Propaga il valore precedente (forward fill)
*bfill() / backfill() → Propaga il valore successivo (backward fill)
*interpolate() → Interpola i valori mancanti
*
- Manipolazione delle Colonne
*assign() → Aggiunge colonne
*astype(dtype) → Cambia il tipo di dati
*convert_dtypes() → Converte automaticamente i tipi di dati
*drop(columns) → Elimina colonne
*insert(loc, column, value) → Inserisce una colonna
*rename(columns) → Rinomina colonne
*set_index(keys) → Imposta una colonna come indice
*reset_index() → Reset dell'indice
*
- Manipolazione delle Righe
*drop(index) → Elimina righe
*drop_duplicates() → Rimuove righe duplicate
*duplicated() → Indica righe duplicate
*reindex() → Cambia l'indice
*sort_values(by) → Ordina per valori
*sort_index() → Ordina per indice
*swapaxes() / swaplevel() → Scambia righe/colonne o livelli dell'indice gerarchico
*
- Operazioni tra DataFrame
*align() → Allinea due DataFrame sugli indici
*combine() → Combina due DataFrame con una funzione
*combine_first() → Riempie i valori NaN con un altro DataFrame
*compare() → Confronta le differenze tra due DataFrame
- Unione e Aggregazione
*append() → Aggiunge righe
*concat() → Concatena DataFrame
*merge() → Merge tra DataFrame
*join() → Join tra DataFrame
*
- Raggruppamenti e Pivot
*groupby() → Raggruppa per colonna
*pivot(index, columns, values) → Crea una tabella pivot
*pivot_table() → Pivot con funzioni di aggregazione
*crosstab() → Tabella di contingenza
*
- Operazioni Matematiche
*add() / sub() / mul() / div() → Addizione, sottrazione, moltiplicazione, divisione
*pow() → Potenza
*mod() → Modulo
*dot() → Prodotto matriciale
*truediv() → Divisione
*floordiv() → Divisione intera
*
- Metodi per Serie Temporali
*asfreq() → Cambia la frequenza dei dati
*asof() → Trova l'ultimo valore disponibile prima di un determinato timestamp
*between_time(start, end) → Filtra i dati tra due orari
*at_time(time) → Seleziona righe di un determinato orario
*resample(rule) → Raggruppa dati temporali
*rolling(window) → Finestra mobile
*expanding() → Statistiche cumulative
*shift(periods) → Sposta i dati avanti/indietro
*pct_change() → Calcola la variazione percentuale
*tz_convert(tz) → Converte il fuso orario
*tz_localize(tz) → Imposta il fuso orario
*
- Metodi di Input/Output
*to_csv(), to_excel(), to_json(), to_sql(), to_parquet(), to_xml() → Salva in vari formati
*from_dict(), from_records() → Crea DataFrame da dizionario o lista di tuple
*to_numpy() → Converte in array NumPy
*to_string(), to_markdown() → Esporta in testo
*to_clipboard() → Copia il DataFrame negli appunti
*
- Altri Metodi Utili
*copy() → Crea una copia
*equals() → Confronta due DataFrame
*eval(expr) → Valuta un'espressione su colonne
*explode() → Espande liste dentro colonne
*iterrows() / itertuples() → Itera sulle righe
*map(func) / apply(func) / applymap(func) → Applica funzioni su colonne o elementi
*mask(cond, value) → Sostituisce valori basati su condizione
*squeeze() → Converte DataFrame a Serie se ha una sola colonna
